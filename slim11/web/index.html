About Slim11 Builder

      
A cross-platform Windows 11 ISO trimmer. Version .

      

        
Built on the work of Tiny11 Builder

        
Slim11 exists because of ntdev and the
          Tiny11 Builder project,
          including its WinUI app.
          The idea, the Tiny11 / Custom build modes, the step-by-step wizard and the choice of what a lean Windows should drop all come from there.
          This app is an independent rewrite for Linux and macOS as well as Windows; it contains no Tiny11 Builder code.

        
If Slim11 is useful to you, please support the original author:
          GitHub Sponsors ·
          Patreon ·
          Ko-fi

        
The look follows Microsoft's WinUI / Fluent design language. Image work is done by
          wimlib (Eric Biggers) and ISO writing by
          pycdlib (Chris Lalancette).
